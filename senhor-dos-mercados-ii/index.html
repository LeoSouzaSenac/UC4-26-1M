01CLASSES E OBJETOSA fundação

A Sociedade se reúne

Na estalagem do Pônei Parcelado, Seu Zé convoca a resistência. Para iniciar a viagem, cada integrante precisa existir no mundo — e possuir atributos próprios.

Sua missão

  • Crie uma classe base chamada Personagem.
  • Todo personagem deve possuir nome, vida, vidaMaxima, ataque e defesa.
  • Implemente um constructor para receber os dados necessários.
  • Crie um método exibirStatus() que mostre os atributos no terminal.
  • Instancie, inicialmente, Seu Zé, Fredo, Samuel e Diegolas.
✦ Marco da missãoO menu deve permitir visualizar os membros da Sociedade e seus atributos.
Conceitos: classes, objetos, atributos, métodos, constructor
02ENCAPSULAMENTOO segredo do mercadinho

Os pontos de vida são sagrados

Um espião da Rede Ômega tentou alterar a vida de Seu Zé diretamente para −999. Dona Marlene declarou: “Aqui ninguém mexe nos nossos dados sem autorização!”

Sua missão

  • Proteja os atributos necessários com private ou protected.
  • Crie getters para consultar a vida atual e a vida máxima.
  • Implemente receberDano(valor) e curar(valor).
  • Impeça que a vida fique abaixo de 0 ou acima da vida máxima.
  • Impeça que dano ou cura negativos produzam efeitos indevidos.
  • Crie estaVivo() para verificar se o personagem pode agir.
✦ Marco da missãoTeste situações extremas: dano maior que a vida, cura exagerada e valores negativos.
Conceitos: private, protected, getters, validação
03HERANÇAOs heróis se revelam

Nem todo herói usa o mesmo cupom

Enquanto Seu Zé desembainha o Facão de Cortar Salame, Diegolas prepara suas Baguetes Élficas e Samuel levanta o Escudo do Rancho. A Sociedade tem habilidades diferentes.

Sua missão

  • Crie pelo menos três classes derivadas de Personagem: Guerreiro, Arqueiro e Guardiao.
  • Utilize extends e super() adequadamente.
  • Defina uma característica própria para cada classe (por exemplo, força extra, precisão ou proteção).
  • Distribua os membros da Sociedade entre as classes criadas.
  • Não replique os atributos da classe base desnecessariamente.
✦ Marco da missãoSeu Zé, Diegolas e Samuel devem compartilhar uma base, mas funcionar como personagens diferentes.
Conceitos: extends, super, reutilização de código
04POLIMORFISMOA emboscada

O ataque à Ponte do Fiado

Os Fiscais de Preços bloquearam a passagem. Os três heróis recebem a mesma ordem: atacar. Mas cada um responde à sua maneira.

Sua missão

  • Defina uma operação de ataque na classe base.
  • Sobrescreva atacar() nas classes derivadas, com resultados diferentes.
  • O ataque deve afetar a vida de um inimigo válido.
  • Armazene os heróis em uma coleção do tipo Personagem[].
  • Mostre que o mesmo método funciona para diferentes tipos de personagem.
  • Impeça personagens derrotados de atacar.
✦ Marco da missãoUma mesma opção do menu deve executar ataques diferentes, de acordo com o herói selecionado.
Conceitos: sobrescrita de métodos, polimorfismo
05INTERFACESOs contratos da aliança

O Conselho do Código

Dona Marlene revela três pergaminhos antigos. Nem todo aventureiro pode fazer tudo: quem promete curar precisa saber curar; quem promete equipar precisa saber equipar.

Sua missão

  • Crie a interface Curavel, com uma operação de cura.
  • Crie a interface Equipavel, com uma operação para equipar um item.
  • Crie a interface HabilidadeEspecial, com uma operação de habilidade especial.
  • Faça pelo menos uma classe implementar cada interface com implements.
  • Crie uma classe que implemente duas interfaces ao mesmo tempo.
  • Use ao menos uma interface como tipo de parâmetro de uma função ou método.
✦ Marco da missãoO programa deve demonstrar, na prática, que as interfaces definem contratos que as classes cumprem.
Conceitos: interface, implements, contratos, tipagem
06MENU INTERATIVOEscolha seu destino

O caminho se divide

Fredo olha para a esquerda: os depósitos da Rede Alfa. Samuel olha para a direita: os caminhões da Rede Ômega. Seu Zé só quer saber onde tem café. A decisão agora é sua.

Sua missão

  • Instale e utilize readline-sync para ler escolhas no terminal.
  • Crie um menu principal que continue aberto até o usuário sair.
  • Permita listar personagens, escolher um herói, iniciar combate e consultar o progresso da aventura.
  • Trate opções inválidas, personagens inexistentes e tentativas de atacar após a derrota.
  • Exiba mensagens compreensíveis a cada ação.

07INTEGRAÇÃO FINALA batalha pelas duas redes

O Cerco dos Mercadinhos

Os dois exércitos avançam. Primeiro surge um Fiscal de Preços da Rede Alfa. Depois, um Operador de Ofertas da Rede Ômega. Ao longe, os sinos anunciam um inimigo maior.

Sua missão

  • Crie pelo menos três inimigos diferentes, incluindo um chefe final: Balrog do Boleto.
  • Implemente combate por turnos entre o herói escolhido e o inimigo.
  • Calcule o dano considerando ataque e defesa, evitando resultados negativos.
  • Após cada ação do jogador, permita que o inimigo vivo contra-ataque.
  • Determine vitória e derrota corretamente; ninguém pode lutar após chegar a 0 de vida.
  • Ao vencer cada confronto, desbloqueie o próximo até chegar ao Servidor da Perdição.

08DESFECHO E QUALIDADEO Servidor da Perdição

O destino do Cupom Único

Após a última batalha, Fredo chega ao Servidor da Perdição. A Sociedade conseguiu sobreviver, mas o destino da Terra dos Mercados ainda depende de uma última escolha.

Sua missão

  • Crie um encerramento para a aventura após a derrota do chefe.
  • Mostre um resultado final e dê a opção de iniciar novamente.
  • Organize o projeto em múltiplos arquivos, separando classes, interfaces e a execução principal.
  • Adicione um README.md explicando a proposta, instalação, execução, estrutura e conceitos utilizados.
  • Verifique se o projeto executa do início ao fim sem erros.
✦ Objetivo finalEntregar um RPG jogável, e não apenas um conjunto de classes sem conexão.
Conceitos: organização, documentação e revisão

ANTES DE PARTIR

Prepare seu arsenal

O projeto deve ser desenvolvido em TypeScript e executado no terminal com Node.js.

PASSO 01

Inicie o projeto

npm init -y
npm install -D typescript ts-node @types/node
PASSO 02

Configure o ambiente

npx tsc --init
npm install readline-sync
npm install -D @types/readline-sync
PASSO 03

Organize o código

src/
├── personagens/
├── inimigos/
├── interfaces/
└── main.ts
README.md
package.json
tsconfig.json

Estrutura sugerida: os nomes e a organização podem mudar, desde que façam sentido.

Importante: Configure o TypeScript conforme o padrão trabalhado em aula. Se usar imports ES Modules ou CommonJS, mantenha a configuração e a forma de execução coerentes. Para executar, configure um script no package.json ou use o procedimento que já foi ensinado.

AS LEIS DA TERRA DOS MERCADOS

Regras do desafio

A criatividade é bem-vinda. Os requisitos técnicos, porém, são obrigatórios.

  • 01
    TypeScript obrigatório

    O sistema deve usar classes, tipos e interfaces de TypeScript, não apenas JavaScript com outra extensão.

  • 02
    Aplicação executável

    O jogo deve funcionar pelo terminal, aceitar entradas e apresentar início, combates e desfecho.

  • 03
    POO de verdade

    Classes, encapsulamento, herança, polimorfismo e interfaces devem fazer parte da lógica, não existir somente para cumprir tabela.

  • 04
    Identidade própria

    É permitido criar novos personagens, habilidades e falas, desde que a aventura mantenha o tema e cumpra as missões.

  • 05
    Sem código decorativo

    O programa precisa utilizar as classes e interfaces implementadas durante a execução.
